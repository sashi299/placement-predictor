# Placement Readiness Digital Twin

An AI-powered student placement prediction system built using Machine Learning and Streamlit.

## Features

- Placement Readiness Prediction
- Company Fit Analysis
- Readiness Score
- Confidence Analysis
- Interactive Streamlit Dashboard

## Technologies Used

- Python
- Pandas
- Scikit-Learn
- Random Forest
- Streamlit
- Joblib

## Dataset Features

- CGPA
- Aptitude Score
- Coding Score
- DSA Score
- Communication Score
- Projects
- Internships
- Backlogs

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
